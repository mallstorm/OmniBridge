# Этап 1 ТЗ 1.0 — RC Stabilization

Версия результата: `0.3.2-rc6`.

Этап закрывает текущие release blockers без изменения основного UI 3.0. Подробный перечень исправлений и проверок находится в корневом `RELEASE_REPORT.md`.

Ключевой результат: Account Connectors получили обязательный preflight, ChatGPT browser flow по умолчанию передан официальному `codex login`, Gemini OAuth усилен строгой Desktop OAuth validation, а maintenance pipeline получил проверяемые backups и rollback после restore health failure.

Следующий этап: **Persistence 2.0**.
