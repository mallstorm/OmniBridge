# Устранение неполадок

## Базовый порядок диагностики

Сначала запускайте `doctor.ps1`, затем FAST. Не начинайте с FULL, если FAST уже падает.

## GUI не открывается

Проверьте Windows PowerShell 5.1 и WPF:

```powershell
Add-Type -AssemblyName PresentationFramework
```

Если WPF исправен, запустите `interface-ru.ps1` вручную и прочитайте текст ошибки. В качестве резерва используйте консольное меню.

## Ошибка SHA256 при bootstrap

Не отключайте проверку. Удалите соответствующий архив из `downloads\` и повторите bootstrap. SHA mismatch означает повреждённый или неожиданный файл.

## GitHub 401/403

Проверьте:

- токен не истёк;
- private repo включён в Repository access;
- `Contents` имеет `Read`;
- организация не требует дополнительного одобрения токена.

## `go test -race` сообщает об отсутствии compiler/CGO

Повторите bootstrap с LLVM-MinGW. Doctor должен определить C compiler. Для race используется локальный `CC/CXX`, а не глобальный Visual Studio toolchain.

## `govulncheck` не работает офлайн

Это нормально для свежей vulnerability database. Используйте FULL офлайн, продолжайте разработку и повторите online gate позже.

## DPAPI test падает

DPAPI acceptance требует настоящую Windows-сессию пользователя. Не используйте Wine или урезанный контейнер для этого пункта. Убедитесь, что Windows PowerShell 5.1 запускается нормально.

## XAML validation падает

Проверьте WPF и затем вручную:

```powershell
.\scripts\validate-ui.ps1 -Root $PWD
```

## FAST зелёный, FULL красный

Смотрите, на каком дополнительном gate произошла ошибка: race, govulncheck, resources, XAML/PS5.1, DPAPI или Windows compile. Не меняйте остальные части pipeline, пока конкретный gate не локализован.

## Release ZIP не создаётся

Сначала выполните быструю сборку. Если quick build проходит, проблема находится в validation/package stage. Проверьте последний report и вывод `build-release.ps1`.

## Антивирус удаляет EXE

Проверьте quarantine и журнал защиты Windows. Не отключайте защиту глобально; при необходимости разрешите только рабочую папку на время локальной инженерной сборки.

## Нужно полностью очистить cache

Используйте `clean.ps1` с параметрами cache. Не удаляйте `fallback`, `source` или `tools` без необходимости.
