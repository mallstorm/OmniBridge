# Безопасность переносной среды

## Модель доверия

Среда выполняет PowerShell и Go с правами текущего пользователя Windows. Рабочую папку следует считать инженерной зоной: не запускайте из неё неизвестные скрипты и не подменяйте архивы toolchain.

## SHA256 toolchain

Закреплённые архивы Go, PowerShell и LLVM-MinGW должны приниматься только после проверки SHA256. При несовпадении hash bootstrap обязан завершиться fail-closed.

## GitHub PAT

Для private source sync рекомендуется отдельный fine-grained PAT:

- Repository access: только `mallstorm/OmniBridge`;
- Contents: Read-only;
- без Administration;
- без Actions write;
- без Secrets;
- с коротким сроком действия.

GUI передаёт PAT дочернему sync-процессу через переменную окружения. Он не должен попадать в command line, config, reports или source metadata.

## Секреты AI-провайдеров

Не помещайте в portable environment реальные API keys, browser cookies или session exports. Для runtime-проверок OmniBridge используйте штатный Secret Store/DPAPI.

## Что не должно попадать в snapshots/release

- `.env`;
- `credentials.json`;
- `secrets.json`;
- `.pfx` / `.p12`;
- приватные `.key`;
- GitHub PAT;
- браузерные сессии.

Проектный release pipeline должен сохранять fail-closed secret-like file scan.

## Telemetry

Portable DEV Shell устанавливает `GOTELEMETRY=off`, а `GOTOOLCHAIN=local`, чтобы сборка не подменяла toolchain автоматически.

## Offline archive

OFFLINE ZIP содержит исполняемый toolchain. Храните его как доверенный build artifact и при переносе сверяйте внешний SHA256 архива.
