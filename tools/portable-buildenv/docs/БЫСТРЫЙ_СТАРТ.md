# Быстрый старт

## Первый запуск

1. Распакуйте среду, например в `D:\OmniBridge-Portable`.
2. Запустите `START.cmd`.
3. Нажмите **Скачать и развернуть**.
4. После bootstrap введите read-only GitHub PAT и нажмите **Скачать текущую ветку**.
5. Запустите **Проверить среду**.
6. Запустите **FAST-проверка**.
7. Если FAST зелёный — запустите **FULL + govulncheck**.
8. Для готовой сборки нажмите **LOCAL RELEASE**.

## Где результат

- EXE/ZIP: `dist\`
- отчёты: `reports\`
- snapshots: `snapshots\`
- исходники: `source\OmniBridge\`

## Если GitHub недоступен

Используйте импорт локальной папки/ZIP или аварийный RC7 fallback.

## Если сети нет вообще

Запускайте FULL/LOCAL RELEASE офлайн. Позже повторите свежий `govulncheck` при наличии сети.

## Если GUI не запускается

Используйте резервное консольное меню или напрямую `doctor.ps1`, `validate.ps1`, `build.ps1`, `release.ps1`.
